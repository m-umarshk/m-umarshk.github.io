# Programming Fundamentals – My First Programming Course

<img src="/assets/images/programming-fundamentals.jpeg"
alt="Programming Fundamentals"
style="width:100%; border-radius:12px; margin-bottom:20px;">

Programming Fundamentals was my first programming subject in the Computer Engineering program, and it introduced me to the world of Python programming. Before joining university, I had very little knowledge about coding, so everything was new to me. During the first few weeks, I learned the basics of programming, including algorithms, flowcharts, variables, data types, input and output, operators, and writing simple Python programs. At first, understanding programming logic was challenging, but with regular practice I became more confident in writing and understanding code.

As the semester continued, I learned important Python concepts such as conditional statements (if, elif, else), loops (for and while), functions, lists, tuples, dictionaries, and basic file handling. Every lab session gave me the opportunity to practice these concepts by solving programming problems. Writing my first Python program and seeing it execute successfully was an exciting moment that motivated me to keep learning.

To improve my understanding outside the classroom, I regularly watched Dr. Bilal's Python Programming lectures on YouTube. His teaching style made complex programming concepts easy to understand, and his practical examples helped me strengthen my problem-solving skills. Whenever I found a topic difficult, I revised it through his lectures, which greatly improved my confidence in Python programming.

Dr. Bilal's YouTube Channel:
https://www.youtube.com/@DrBilal

By the end of the semester, Programming Fundamentals had become one of my favorite subjects. It gave me a strong foundation in Python programming, logical thinking, and problem-solving. The knowledge I gained from this course later helped me understand advanced technologies such as Data Science, Machine Learning, and Artificial Intelligence. Looking back, I consider this subject the starting point of my journey as a computer engineering student.
